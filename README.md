🧮 Python Calculator (Interactive Console App)

A simple, interactive Python calculator built using functions, loops, and dictionaries. This mini project allows users to perform basic arithmetic operations—addition, subtraction, multiplication, and division—in a smooth, continuous way.

🔧 Features
	•	Supports basic operations: +, -, x, /
	•	Allows users to chain calculations using previous results
	•	Automatically restarts a new calculation if the user chooses to reset
	•	Clean and user-friendly terminal interface
	•	Uses function mapping via a dictionary for better scalability

🚀 How It Works
	1.	User enters the first number.
	2.	User picks an operation (+, -, x, /).
	3.	User enters the second number.
	4.	Result is calculated and shown.
	5.	User can either:
	•	Continue calculating with the result, or
	•	Start a new calculation

💡 Example

Enter the 1st number: 
10
+
Enter the 2nd number: 
5

The result is: 15

Type 'y' to continue with 15 or 'n' to start new:
